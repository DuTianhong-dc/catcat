# catcat · 机械设计(CAD)

「猫包」四足机器猫(catcat)的 SolidWorks 设计文件,含 0.0 ~ 3.3 全系列。

> 文件格式:SolidWorks 2024(及以上)。

## 目录

| 目录 / 文件 | 内容 |
|---|---|
| `机械猫0.0/` | 初代概念:骨架草图 + 关节概念 |
| `机械猫1.0/` | 实体化第一版:舵机关节模组 |
| `机械猫1.1/` | 模块化拆分:关节 / 前肢 / 后肢 / 躯干 |
| `机械猫2.0/` | 连杆式腿部结构(曲柄 + 从动杆) |
| `机械猫3.0/` | **当前设计**;`仿真/` 为导出训练模型的简化装配 |
| `自己的设计库/` | 自绘采购件(飞特舵机、接插件等) |
| `通用模型/` | 常用件装配库(电池、驱动板、ESP32 外壳等) |
| `BOM_复刻物料清单.md` | **复刻物料清单**(按此采购) |
| `机械猫零件采购清单.xlsx` | 原始采购记录(含价格,存档) |

## ⚠️ 第三方模型说明

轴承、卡簧、垫片、螺钉、ESP32-CAM 硬件、IMU、SG90 云台等**第三方来源模型**
不在本仓库分发,已从各目录剔除。

- 缺失位置与替代获取方式:见各目录下 `_缺件说明.md`
- 打开装配体时提示"找不到文件"属正常现象 —— 按 BOM 采购实物、忽略提示即可

## 约定

- 装配结构保持与设计时一致(未重命名 / 未重排)
- `机械猫3.0/仿真/` 的"仿真××"副本供导出训练模型使用,与主设计同步维护
- 本仓库仅含**自研**与**自绘**模型;采购件规格见 BOM
